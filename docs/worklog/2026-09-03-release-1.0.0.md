# v1.0.0

ブランチ: `chore/release-1.0.0`

## 何を

`package.json` のバージョンを `0.1.0` から `1.0.0` へ上げ、
タグ `v1.0.0` と GitHub リリースを作成した。

## なぜ 1.0.0 か

- ロードマップの P1〜P6 がすべて完了している
- 本番環境（Vercel）で実際に稼働している
- 登録の制限・プライバシーポリシー・アカウント削除が揃い、
  自分以外が触れる状態になっている

「作りかけを動かしている」段階を抜けたため、0.x を続ける理由が無くなった。

## この版までに入ったもの

| 区分 | 内容 |
|---|---|
| 基盤 | 認証 / プロジェクト / フォルダ・ファイル / Markdown エディタ / ダッシュボード |
| AI | タスク抽出・改善提案、日程算出、RAG チャット、使用量の記録と表示 |
| 予定 | カレンダー UI、`.ics` 書き出し、Google Calendar 同期（再接続の通知つき） |
| 履歴 | 記録・一覧・差分表示・検索・タグ・容量監視 |
| 連携 | iOS ショートカット / Webhook API |
| 運用 | 本番デプロイ、プライバシーポリシー、アカウント削除 |
| 制限 | 招待コードによる登録制限、操作前のパスワード再確認 |

## どう確認したか

lint / typecheck / test（729 件）/ build がグリーン。
