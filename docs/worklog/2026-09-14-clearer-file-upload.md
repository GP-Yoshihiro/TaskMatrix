# アップロード欄を分かりやすくする

ブランチ: `fix/clearer-file-upload`

## 何が起きていたか

「ファイルを選択」が**押せる場所だと認識できなかった**との指摘。

原因は、ブラウザ既定の `<input type="file">` をそのまま置いていたこと。
見た目が環境任せで小さく、周りの文字と区別が付かない。

## 直したこと

枠で囲った広い領域にし、次をその場に出した。

- **「ファイルを選ぶ」**（ボタンの見た目にする）
- ドラッグでも入れられること
- **対応する形式**と**大きさの上限**
- 選んだあとは**ファイル名と大きさ**

## 設計の判断

### 選ぶ前に、何を選べるかを出す

選んでから断られるより、選ぶ前に分かるほうがよい。
対応形式と上限は定数から組み立てるため、形式を足せば自動で追従する。

### 選ぶ前はアップロードを押せないようにする

押しても必ず失敗する操作を誘わない。

### 入力欄は隠すが、消さない

`display: none` にすると**キーボードで届かなくなる**。
位置をずらして見えなくし、焦点は当たる形にした。
焦点が当たると枠を強調し、どこにいるかが分かるようにしている。

### ドラッグは入力欄へ入れてから送る

落としたファイルを直接送らず、入力欄の中身にする。
送信の経路を 1 つに保ち、選び方による違いを作らない。

- `components/features/files/__tests__/file-upload-form.test.tsx` 10 件
  （押せる言葉、ドラッグの案内、対応形式、上限、未選択の表示、
  選ぶ前は押せないこと、選んだあとの名前と大きさ）
- lint / typecheck / test（971 件）/ build がグリーン
- **実際に画面を出して確認した**（確認用のページを一時的に作り、削除済み）
  - 点線の枠と青いボタンが出ること
  - キーボードで到達すると枠が強調されること
