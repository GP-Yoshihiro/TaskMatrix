# 編集枠を、選んだ行の直下に出す

ブランチ: `fix/inline-task-edit`

## 何が起きていたか

タスク一覧で「編集」を押すと、**一覧の先頭に編集枠が出ていた。**
どの行を編集しているのかが分からず、一覧が長いと押した場所から離れてしまう。

## 直したこと

編集枠を、**選んだ行の直下**に出すようにした。

- 一覧表示・ボード表示の**両方**に適用
- 描き分けず、同じ関数から出す。分けると片方だけ挙動が変わる
- 別の行の「編集」を押すと、そちらへ移る（2 つ同時には開かない）

新規作成の枠は従来どおり一覧の上に出す。**まだ行が無いため、
その下に出しようがない。**

## どう確認したか

- `components/features/tasks/__tests__/task-manager.test.tsx` 6 件
  - はじめは出さない
  - **押した行の中に出る**
  - **押していない行には出ない**
  - **一覧の先頭には出ない**（今回の修正点をそのまま固定）
  - 別の行を押すとそちらへ移る
  - キャンセルで閉じる
- lint / typecheck / test（940 件）/ build がグリーン
- 起動してコンパイルエラーが無いことを確認
