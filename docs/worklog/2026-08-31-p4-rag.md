## 見つかった問題と対処

### 成功メッセージが赤字の警告として表示されていた

成功と失敗で同じ状態を使い、常に `role="alert"` かつ赤字で描画していた。
「N 件の検索用データを作成しました」という成功の知らせが
エラーのように見えてしまう。

成否を区別して持ち、成功は `role="status"` かつ通常色で出すようにした。

## 検証時につまずいた点

ブラウザ自動操作で `form.requestSubmit()` を使ったところ、
React の `action` が起動せず送信されなかった。
送信ボタンを実際にクリックすると正常に動いた。
アプリの不具合ではなく、検証手順側の問題だった。
