
## 判断したこと

### `git mv` で移す

`git mv` を使い、履歴を保った。
削除して作り直すと、その行が「いつ・なぜ書かれたか」を追えなくなる。

### 汎用的な文言のコメントは書かない

「〜を表示するコンポーネント」のような、
名前を読めば分かることを書き足しても意味がない。

**なぜそうしているのか**を書いた。例:

> 差分は一覧に載せず、開いたときだけ取りに行く。
> 全件分の変更行を一覧に積むと、無限スクロールで重くなるため。

> 抽出した時点では保存しない。利用者が選んだものだけを登録する。
> 再抽出しても既存のタスクが失われないようにするため。
