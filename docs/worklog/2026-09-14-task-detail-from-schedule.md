# 予定からタスクの詳細を開き、編集できるようにする

ブランチ: `feature/task-detail-from-schedule`

## 何を

ガントチャートの**工程名を押すと、そのタスクの詳細がダイアログで開く。**
そこから編集もできる。

## なぜ

予定を見ていて「このタスクは何だったか」を確かめたくなったとき、
タスク画面へ移ってから戻るのは手間が大きい。

## 作りの変更

行はこれまで**タスクの識別子を持っていなかった**（工程名と担当の組が鍵だった）。
`CalendarEntry` と `GanttSource`、ガントの行に `taskId` を通した。

## 設計の判断

### 詳細を先に出し、編集は押したときだけ開く

いきなり入力欄が並ぶと、見るだけのときに読みにくい。

### タスクが変わったら部品ごと作り直す

閲覧と編集の切り替えを副作用で戻すと、描き直しが連鎖する
（lint も error として指摘する）。**鍵を変えて作り直せば、
状態は自然に初期値へ戻る。**

### 保存したら予定を作り直す

担当や想定日程が変われば、ガントチャートの色分け・並べ替え・
日程の長さも変わる。前回の指摘（更新の影響先をまとめて作り直す）と同じ考え方。

### 開く手段が無ければ押せないようにする

押しても何も起きないものを、押せると見せない。

### Escape でも閉じる

ダイアログを閉じる手段が 1 つだけだと、手が止まる。
