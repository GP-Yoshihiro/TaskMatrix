# タスクの複数選択と、まとめて削除

ブランチ: `feature/task-bulk-select`

## 何を

タスクを複数選び、まとめて削除できるようにした。

- 各タスクに選択欄。選んだものは枠で示す
- 「すべて選択」で表示中のものをまとめて選ぶ
- 「選択したタスクを削除」で、確認のうえまとめて消す

## 設計の判断

### 表示されていないものには触らない

絞り込みや表示の切り替えで隠れているものを、知らないうちに消させない。
「すべて選択」も、削除の対象も、**表示中のものだけ**。
件数の表示も表示中のものだけを数える。実際に消える数と食い違わせない。

### 選んだものは枠でも示す

印だけだと、どれを選んだか見落とす。

### 消せた件数を返す

行レベルセキュリティにより、他人のタスクは混ぜても消えない。
求めた数と違えば、画面でその旨を伝える。

### 1 回の問い合わせで消す

1 件ずつ往復すると、件数だけ待たされる。

### 確認を挟む

取り消せない操作を、確認なしに実行しない。
