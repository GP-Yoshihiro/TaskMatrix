## 直列取得の解消

### ファイル画面

- 変更前: ファイル → 版 → プロジェクト名 → タグ 2 種 → 予測（5 段）
- 変更後: **ファイル・プロジェクト名・タグ 2 種・予測を 1 度に待ち**、
  ファイルの情報が要る「版」だけを後から引く（2 段）

### 変更履歴画面

- 変更前: プロジェクト名 → 整理 → 一覧＋タグ（3 段）
- 変更後: **プロジェクト名・タグ・整理を 1 度に待ち**、一覧を後から引く（2 段）

**一覧は整理のあとに引く。** 先に引くと、直後に消える行を並べてしまう。
整理の失敗は `catch` で握り、履歴は見られるようにした（従来どおり）。
