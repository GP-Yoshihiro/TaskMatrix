# 使い方の案内ページ

ブランチ: `docs/user-guide`

## 何を

`/guide` に、開発の知識が無い人向けの案内ページを追加した。
ログイン画面・新規登録画面からリンクしている。

## なぜ

本番環境を家族に渡すことになった。アプリ自体は URL を開けば使えるが、
README にはセットアップ手順しか無く、**使う人向けの説明が無かった**。

## どこに置いたか

アプリ内の公開ページにした（`(app)` の外／`PROTECTED_PREFIXES` にも含めない）。

- 渡すものが **URL 1 つで済む**
- **アカウントを作る前から読める**。登録手順そのものが書いてあるため、
  ログインが要る場所に置くと意味をなさない

## 書いた内容

1. できること
2. 使い始める（招待コードでの登録）
3. **アイコンから起動できるようにする**（iPhone / Android / Mac / Windows）
4. 画面の見方（実際の項目名と絵文字に合わせた）
5. ひととおりの流れ（アップロード → AI タスク抽出 → スケジュール算出）
6. Google カレンダー連携（**「確認されていないアプリ」の警告が出ることを明記**）
7. 困ったとき
8. 知っておいてほしいこと（外部送信・使用量・アカウント削除）

## 判断したこと

- **画面の実際の表記に合わせた。** ナビゲーションの項目名・ボタンの文言
  （「AI タスク抽出」「スケジュール算出」「Google カレンダー連携」「アップロード」）を
  コードから拾って書いた。案内が実物とずれると、かえって迷わせる
- **Google の警告画面に先に触れた。** 何も知らずに出会うと故障だと思って止まる。
  審査を受けていないためであること、権限は app-created のみであることを書いた
- 専門用語を避けた。「PWA」「デプロイ」「リポジトリ」などは使っていない

## 事前に確かめたこと

- PWA のアイコン（192 / 512 / maskable）が本番で配信されている（いずれも 200）。
  配信されていなければ「ホーム画面に追加」しても正しく出ない
- `manifest.webmanifest` が本番で 200

## どう確認したか

lint / typecheck / test（729 件）/ build がグリーン。`/guide` がルートに追加されたことを確認。
