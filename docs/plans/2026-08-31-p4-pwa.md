# TaskMatrix 第4フェーズ（PWA 対応）実装計画

> **エージェント実行者へ:** `superpowers:executing-plans` を用いてタスク単位で実装すること。

**ゴール:** iPhone / iPad / Mac のホーム画面に追加してアプリとして起動でき、
オフライン時は日本語で状況を伝える状態にする。

**アーキテクチャ:** Service Worker は自前実装。判定ロジックを純粋関数に切り出して
テストする。利用者のデータはキャッシュしない。

**設計書:** `docs/specs/2026-08-31-p4-pwa-design.md`

---

## グローバル制約

- UI 文言・コメント・コミットメッセージはすべて**日本語**（R-02）
- 機能ごとに新規ブランチ。`main` へ直接コミットしない（R-03）
- 各タスクの最後に `lint` → `typecheck` → `test` → `build`。
  すべてグリーンでのみコミット（R-05 / R-06）
- テストを先に書く（R-12）
- **依存パッケージを追加しない**（R-19）
- **GET 以外のリクエストに Service Worker が介入しない**こと。
  Server Actions は POST であり、壊すと全機能が止まる
- `/api/*` と Supabase / Gemini への通信をキャッシュしない
- テーマ色は既存のトークン `#0071e3`（Apple テーマのアクセント）を使う

- [ ] **Step 4: 判定ロジックを実装する**

`lib/domain/pwa.ts`:

```typescript
export type CacheStrategy = 'network-first' | 'cache-first' | 'passthrough'

/** Service Worker が事前に取得しておく、利用者データを含まない資源 */
export const APP_SHELL = [
  '/offline',
  '/manifest.webmanifest',
  '/icons/icon-192.png',
  '/icons/icon-512.png',
  '/icons/apple-touch-icon.png',
] as const

const CACHE_FIRST_PREFIXES = ['/_next/static/', '/icons/']
const CACHE_FIRST_EXACT = ['/manifest.webmanifest']

/**
 * リクエストごとの扱いを決める。
 *
 * GET 以外には一切介入しない。Server Actions は POST であり、
 * 介入すると全機能が止まる。
 * 別オリジン（Supabase / Gemini）にも手を出さない。
 */
export function chooseStrategy(input: {
  method: string
  url: string
  mode: string
}): CacheStrategy {
  if (input.method !== 'GET') return 'passthrough'

  let path: string
  let isSameOrigin: boolean
  try {
    const url = new URL(input.url)
    path = url.pathname
    isSameOrigin = typeof self !== 'undefined' && 'location' in self
      ? url.origin === (self as unknown as { location: Location }).location.origin
      : true
  } catch {
    return 'passthrough'
  }

  if (!isSameOrigin) return 'passthrough'
  if (path.startsWith('/api/')) return 'passthrough'

  if (input.mode === 'navigate') return 'network-first'

  if (CACHE_FIRST_EXACT.includes(path)) return 'cache-first'
  if (CACHE_FIRST_PREFIXES.some((prefix) => path.startsWith(prefix))) return 'cache-first'

  return 'passthrough'
}
```

> **注意**: `isSameOrigin` の判定はテスト環境（jsdom）とワーカー環境の
> 両方で動く必要がある。テストでは `self.location` が
> `http://localhost:3000` になるため、別オリジンの URL は正しく弾かれる。

- [ ] **Step 7: Service Worker を書く**

`public/sw.js`。`lib/domain/pwa.ts` と同じ判定を持たせる。
（Service Worker は import できないため、判定を写す。
テストは `lib/domain/pwa.ts` 側で行い、両者を一致させる。）

```javascript
const CACHE_NAME = 'taskmatrix-shell-v1'

const APP_SHELL = [
  '/offline',
  '/manifest.webmanifest',
  '/icons/icon-192.png',
  '/icons/icon-512.png',
  '/icons/apple-touch-icon.png',
]

const CACHE_FIRST_PREFIXES = ['/_next/static/', '/icons/']
const CACHE_FIRST_EXACT = ['/manifest.webmanifest']

function chooseStrategy(request) {
  if (request.method !== 'GET') return 'passthrough'

  let url
  try {
    url = new URL(request.url)
  } catch {
    return 'passthrough'
  }

  if (url.origin !== self.location.origin) return 'passthrough'
  if (url.pathname.startsWith('/api/')) return 'passthrough'
  if (request.mode === 'navigate') return 'network-first'
  if (CACHE_FIRST_EXACT.includes(url.pathname)) return 'cache-first'
  if (CACHE_FIRST_PREFIXES.some((p) => url.pathname.startsWith(p))) return 'cache-first'

  return 'passthrough'
}

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches
      .open(CACHE_NAME)
      // 1 つ失敗しても全体を止めない
      .then((cache) => Promise.allSettled(APP_SHELL.map((path) => cache.add(path))))
      .then(() => self.skipWaiting()),
  )
})

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) =>
        Promise.all(keys.filter((key) => key !== CACHE_NAME).map((key) => caches.delete(key))),
      )
      .then(() => self.clients.claim()),
  )
})

self.addEventListener('fetch', (event) => {
  const strategy = chooseStrategy(event.request)
  if (strategy === 'passthrough') return

  if (strategy === 'network-first') {
    event.respondWith(
      fetch(event.request).catch(() =>
        caches.match('/offline').then((cached) =>
          cached ?? new Response('オフラインです。', {
            status: 503,
            headers: { 'Content-Type': 'text/plain; charset=utf-8' },
          }),
        ),
      ),
    )
    return
  }

  event.respondWith(
    caches.match(event.request).then((cached) => {
      if (cached) return cached
      return fetch(event.request).then((response) => {
        if (response.ok) {
          const copy = response.clone()
          caches.open(CACHE_NAME).then((cache) => cache.put(event.request, copy))
        }
        return response
      })
    }),
  )
})
```

`components/app/service-worker-register.tsx`:

```tsx
'use client'

import { useEffect, useState } from 'react'
import { Button } from '@/components/ui/button'

export function ServiceWorkerRegister() {
  const [updated, setUpdated] = useState(false)

  useEffect(() => {
    if (!('serviceWorker' in navigator)) return

    navigator.serviceWorker.register('/sw.js').catch(() => {
      // 登録できなくてもアプリは通常どおり動く
    })

    let firstControl = navigator.serviceWorker.controller === null

    function handleChange() {
      // 初回の制御取得は「更新」ではない
      if (firstControl) {
        firstControl = false
        return
      }
      setUpdated(true)
    }

    navigator.serviceWorker.addEventListener('controllerchange', handleChange)
    return () =>
      navigator.serviceWorker.removeEventListener('controllerchange', handleChange)
  }, [])

  if (!updated) return null

  return (
    <div
      role="status"
      style={{
        position: 'fixed',
        insetInline: 16,
        bottom: 16,
        zIndex: 60,
        display: 'flex',
        gap: 10,
        alignItems: 'center',
        justifyContent: 'space-between',
        flexWrap: 'wrap',
        background: 'var(--color-surface)',
        border: '1px solid var(--color-border)',
        borderRadius: 'var(--radius-md)',
        boxShadow: 'var(--shadow-md)',
        padding: 12,
      }}

      <Button size="sm" onClick={() => window.location.reload()}>

    </div>
  )
}
```

**2. プレースホルダ**

「TBD」の類は含まれていない。
Task 1 Step 2 のアイコン生成のみアルゴリズムを文章で示しているが、
出力するファイル・サイズ・色・モチーフ・制約（中央 80%）を指定しており、
使用する標準モジュール（`zlib`）も明記している。

**3. 型の一貫性**

- `CacheStrategy` / `APP_SHELL` / `chooseStrategy` — Task 2 で定義し同タスク内で使用
- `public/sw.js` は `lib/domain/pwa.ts` と同じ判定を持つ。
  Service Worker は import できないため写しになる。**両者がずれると
  テストが実態を保証しなくなる**ので、変更時は必ず両方を直すこと。
  この点を `public/sw.js` の冒頭コメントに明記する。

**4. リスクと対処**

Service Worker は一度誤って配ると利用者の端末に残り続ける。
そのため次を守る。

- `install` で `skipWaiting()`、`activate` で `clients.claim()` を呼び、
  古い版が居座らないようにする
- キャッシュ名にバージョンを付け、`activate` で古いものを消す
- **GET 以外に触れない**ことをテストで固定する
