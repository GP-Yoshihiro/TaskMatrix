# Google 連携の失効を気付ける形にする 実装計画

ブランチ: `feature/google-reconnect`

## 背景

現状の判定はこうなっている。

```
connected={connection !== null}   ← 行があるかを見るだけ
```

**トークンが失効しても「連携済み」と表示され続ける。**
利用者は取り込みボタンを押して初めて失敗に気付く。
予定が同期されていないことに気付かないまま過ごす恐れがある。

## この実装の範囲

- 失効を検知したら記録し、画面で**押す前に**分かるようにする
- 繋ぎ直せば自動で解除する

**7日での失効そのものは Google の公開ステータスの仕様であり、
アプリ側では延ばせない。** これは別途ユーザーの設定作業が必要。

---

## Task 1: マイグレーション `0012_google_needs_reconnect.sql`

`google_connections` に `needs_reconnect boolean not null default false` を追加。

## Task 2: リポジトリ

`setNeedsReconnect(userId, value)` を追加し、`find` の戻り値に含める。

## Task 3: `openGoogleSession`

- 更新に失敗して `reconnect_required` なら印を立てる
- 成功したときに印が立っていれば消す
- **値が変わるときだけ書き込む**（毎回書くと無駄な更新になる）
- **印の読み書きに失敗しても、本来の処理は止めない**（付随的な情報のため）

**テスト:**
- 失効したら印を立てる
- 成功したら印を消す
- すでに正しい値なら書き込まない
- 書き込みに失敗しても結果は変わらない

## Task 4: 画面

- スケジュール画面で `needsReconnect` を渡す
- パネルで**再接続の案内を目立たせ**、取り込み・書き出しを押せなくする
  （押しても失敗するだけで、利用者を無駄に困らせるため）
