# UI ブラッシュアップ 実装計画（第 3 期：コード整理）

ブランチ: `feature/code-structure`

## 背景

`components/app/` に **29 ファイルが平置き**されており、
どれがどの機能のものか、ファイル名から推測するしかない。

## 分け方

機能ごとにフォルダを作る。**画面の並びと対応させる**ことで、
「この画面を直したい」から辿れるようにする。

```
components/
  layout/     骨格（サイドバー・ヘッダー・見出し）※既存
  ui/         どこでも使う部品（ボタン・入力・カード）※既存
  features/
    auth/       ログイン・ログアウト
    projects/   プロジェクトの一覧と作成
    files/      フォルダ・ファイル・Markdown 編集・タグ
    tasks/      タスクの管理と AI 抽出
    schedule/   予定の算出・カレンダー・Google 連携
    chat/       RAG チャット
    history/    変更履歴
    settings/   表示名・テーマ・稼働条件
    api/        連携トークン
    pwa/        Service Worker の登録
```

## 進め方

1. フォルダを作り、`git mv` で移す（履歴を保つ）
2. 取り込み元の記述をすべて直す
3. **各ファイルの先頭に、その部品が何をするものかの説明を付ける**
4. 主要な関数・状態にコメントを付ける
5. 検証

## 注意

- **動きは一切変えない。** 置き場所と説明だけの変更とする
- テストの取り込み元も直す
