# TaskMatrix
フォルダ、タスク、スケジュール管理システムwedアプリケーション

WEBアプリケーション基本設計・仕様書
1. システム概要
システム名称: 統合型ドキュメント・タスク・スケジュール管理アプリケーション（仮）
コンセプト: ドキュメント（フォルダ）を中心に、AIがタスク抽出・スケジュール自動生成を行うAppleエコシステム最適化型プロジェクト管理ツール。
2. 技術スタック・システム構成
区分    テクノロジー / サービス    採用理由・役割
フロントエンド    Next.js (React / TypeScript), PWA    Vercelと親和性が高く、レスポンシブ・PWA対応
バックエンド / DB    Supabase (PostgreSQL, Supabase Auth, Storage)    認証、データ独立、ファイル実体管理、メタデータ管理
AIエンジン    Google AI Studio (Gemini API)    Fast API連携、高度なテキスト・ドキュメント解析（RAG実装）
デプロイ    Vercel    Vercel Edge FunctionsによるAPI統合・CI/CD
コード管理    GitHub    ソースコードおよびアプリ内テキスト/Markdownの履歴管理
対象環境    macOS, iOS, iPadOS, watchOS (PWA / ショートカット)    Apple端末でのシームレスな利用
3. システムアーキテクチャ & データ保持戦略
ファイル実体: Supabase Storage に保存（Word, Excel, PowerPoint, PDF等）。
テキストデータ / 履歴: プレーンテキスト・Markdownおよびドキュメントの差分・更新履歴メタデータを Supabase DB および GitHub API で管理。
カレンダー同期: Google Calendar API による双方向同期、および標準 .ics ファイル（Appleカレンダー用）のインポート/エクスポート出力。
watchOS対応: PWA（Web Push通知）およびiOS「ショートカット」アプリ経由の簡易操作・通知受領。
4. データベース設計案（ER概要）
[Users] 1 --- * [Projects] 1 --- * [Folders] 1 --- * [Files]
   |                 |                                  |
   +--- * [Tasks] <---+----------------------------------+ (AI抽出)
   |        |
   +--- * [Schedules] (Google Calendar / .ics連携)
users: ID, メールアドレス, プラン（Free: 5/Pro: 無制限など拡張性確保）
projects: プロジェクトID, ユーザーID, プロジェクト名, 作成日（最大20個の枠組み制御）
folders / files: フォルダ構造、ファイルパス（Supabase Storage）、バージョン情報
tasks: タスク名, 抽出元ファイルID, ステータス, 優先度, 担当/期限, 不透明点メモ, AI改善提案
schedules: カレンダーイベントID, タスクID, 開始/終了日時, 算出理由（AI記述）
5. 主要機能仕様
① フォルダ・ドキュメント管理
対応フォーマット：Excel (.xlsx), Word (.docx), PowerPoint (.pptx), Text (.txt, .md), PDF
アプリ内簡易Markdownエディタ搭載（サクッとメモ生成）
バージョン履歴表示（誰がいつ更新したかのログ保持）
② AIタスク抽出・改善提案機能（Gemini API）
解析・抽出: 指定フォルダ/ドキュメントを読み込み、タスクを自動リスト化。
品質向上: 不透明な記述の指摘、タスク化に向けた具体的な改善・修正案の提示。
手動調整: 自動抽出されたタスクの手動追加・編集・削除機能。
③ スケジュール自動算出機能
算出機能: タスクの負荷・期限に基づき、AIが最適なスケジュール仮案を出力。
根拠の明記: 「なぜその日時に割り当てたか（算出理由）」を提案時に併記。
確定ワークフロー: 仮データ表示 ➔ ユーザーの「確定」操作でカレンダーへ反映・保存。
連携: Google Calendar同期、Appleカレンダー用 .ics 書き出し。
④ コンテキスト重視 AIアシスタント (RAGチャット)
プロジェクト内のファイルを横断検索し、「〇〇の進捗はどう？」などの質疑応答に対応。
⑤ エコシステム拡張
iOSショートカット / Webhook API: 音声やショートカット経由でのタスク追加・本日の予定参照。
6. 画面一覧（UI/UX設計マップ）
認証ページ: ログイン / 新規アカウント作成（Supabase Auth）
ホーム画面: ダッシュボード（本日のタスク・スケジュール・最近の更新）
プロジェクト一覧: 最大20個のプロジェクトカード表示（追加・削除・設定）
プロジェクト詳細 / フォルダ一覧: ディレクトリ階層表示、ファイルアップロード・新規作成
データ閲覧・編集（エディタ）: ファイルビューアー / Markdownエディタ
タスク管理画面: AI抽出タスク一覧、カンバン/リスト表示、AI改善提案・不透明点カード
スケジュール画面: カレンダーUI（仮データプレビュー、確定アクション、算出理由表示）
Git・変更履歴ページ: ファイルの更新履歴・差分ログ表示
プロジェクト横断AIチャット: RAGベースのファイル横断検索・質疑応答UI
